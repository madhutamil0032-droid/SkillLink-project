 SkillLink – Local Services, Connected

 About the Project
SkillLink is a web-based platform designed to connect customers with local service providers based on their service requirements and location.

 Features
- User Registration and Login
- Customer and Service Provider Accounts
- Profile Management
- Category-Based Service Search
- Location-Based Provider Search
- Provider Availability Management
- Form Validation
- Session Management

 Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- WAMP Server
- phpMyAdmin

 Project Structure
- `index.html` – Home page
- `login.html` – User login
- `register.html` – User registration
- `style.css` – Website styling
- `script.js` – Frontend interactions
- `backend/` – PHP backend files
- `config/` – Database configuration
- `database/` – SQL database file

 How to Run Locally
1. Install WAMP Server.
2. Copy the project folder into the WAMP `www` directory.
3. Start Apache and MySQL.
4. Import `skilllink.sql` using phpMyAdmin.
5. Configure your local database connection.
6. Open `http://localhost/SkillLink-project/` in your browser.

 Project Objective
To make local services more accessible by connecting customers with skilled service providers in their communities.
